# SAGE
The official code implementation of SAGE and the datasets for comparative experiments


The public datasets used in this study are available from the following sources:

\textbf{Early PD Speech}~\cite{hlavnicka2017connected}: \href{https://media.springernature.com/original/springer-static/esm/art\%3A10.1038\%2Fs41598-017-00047-5/MediaObjects/41598_2017_47_MOESM3_ESM.xls}{Download Link}.

\textbf{PhysioNet PD Gait}~\cite{hausdorff2008gaitpdb}: \href{https://physionet.org/content/gaitpdb/1.0.0/}{PhysioNet Data download}.

\textbf{Mendeley PD Voice}~\cite{carron2023pdvoice}: \href{https://data.mendeley.com/datasets/fjd6fcfkwn/1}{Mendeley Data download}.

\textbf{CASAS Dementia SmartHome}~\cite{dawadi2013automated}: \href{https://doi.org/10.5281/zenodo.15713579}{Zenodo Data download}.
